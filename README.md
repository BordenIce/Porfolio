BordenIce — Portfolio

A personal portfolio website showcasing my work in web development, game development and video editing. Built with plain HTML, CSS and a little JavaScript — no frameworks, no build step.

🔗 Live demo: https://bordenice.github.io/Portfolio/ 

✨ Features
Responsive layout — looks good on desktop, tablet and phone
Automatic light / dark theme based on the visitor's system settings
Sticky navigation with smooth scrolling between sections
Project cards with screenshot, description, tech chips, Live Demo and GitHub buttons
Before / After slider for the video editing section
Skills and Contact sections
Lightweight: three source files and a handful of images
📂 Sections
#	Section	What's inside
01	Web Development	Positivos, Minecraft Server Website, Restaurant Menu, Electronics Store, Hdrezka (film platform)
02	Video Editing	Before / After comparison slider and short-form video previews
03	Skills	HTML, CSS, JavaScript, Python, MySQL, Unity, Unreal Engine, Video Editing
04	Contact	Call-to-action for websites, video edits and game prototypes
🛠 Tech Stack
HTML5 — semantic markup
CSS3 — custom properties, Grid, Flexbox, prefers-color-scheme, backdrop-filter
JavaScript (vanilla) — before/after slider
Google Fonts — Bricolage Grotesque, JetBrains Mono

🚀 Getting Started
bash
# 1. Clone the repository
git clone https://github.com/BordenIce/Portfolio.git

# 2. Go to the project folder
cd Portfolio

# 3. Open the page in your browser
#    (just double-click "BordenIce Portfolio.html")

No installation or build tools required. To run a local server instead:

bash
python -m http.server 8000
# then open http://localhost:8000
🌐 Deployment

The site is static, so it can be hosted for free on:

GitHub Pages — Settings → Pages → Deploy from branch → main / root
Netlify — drag and drop the folder or connect the repo

✏️ Customization
Add a project — copy an <article class="card"> block in the HTML, then change the title, description, image and links.
Change colors — edit the CSS variables in :root at the top of style.css.
Change contact email — update the mailto: link in the Contact section.
